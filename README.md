Graph algorithms for KSR TALIT. See https://sca.ksr.ch/doku.php?id=talit:algorithmen

See [this notebook](sbb.ipynb) for an application of the various path finding algorithms over the Swiss Railways network.
## Algorithm player

[docs/index.html](docs/index.html) is a self-contained, iframeable step-by-step player for DFS, BFS and Dijkstra
(same semantics as the course code). Open it without parameters to get an editor that generates embed URLs.
Parameters: `graph` (DOT or Python dict), `algo`, `start`, `end`, `theme`, `accent`, `bg`, `lang`, `speed`, `autoplay`, `legend`
— see the comment at the top of the file. Hosted via GitHub Pages (main branch, `/docs`).
